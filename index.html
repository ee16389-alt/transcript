使用說明

事前準備

  • 需要一個 Gemini API Key（免費）
  • 取得方式：前往 aistudio.google.com → 登入 Google 帳號 → 點「Get API Key」→ 建立新 Key → 複製貼入上方欄位

使用步驟

  1. 將 API Key 貼入「Gemini API Key」欄位
  2. 選擇語言（預設繁體中文）
  3. 選擇是否需要即時翻譯
  4. 點「🎙 麥克風收音」或「🖥 分頁 / 視窗 / 螢幕收音」開始錄音
  5. 錄音完成後點「■ 停止收音」
  6. 等待幾秒，逐字稿自動出現
  7. 點「↓ 下載 Markdown」儲存到本機

三種收音模式

  • 🎙 只收麥克風：只錄自己說話，不收任何瀏覽器聲音。適合語音備忘、獨自說話的場合。
  • 🖥 只收分頁音訊：只收瀏覽器分頁的聲音，完全不收麥克風。適合 YouTube、線上課程、播放影片時，不想混入環境噪音。點按鈕後選分頁並勾選「共享分頁音訊」。電腦靜音也不影響收音。
  • 🎙＋🖥 麥克風＋分頁：同時收麥克風與瀏覽器分頁音訊，兩路合併。適合 Teams/Zoom 開會（自己說話＋對方聲音一起收）。點按鈕後：① 先允許麥克風 → ② 再選音訊來源並勾選音訊共享選項（見下表）。若步驟②取消，會自動退回純麥克風繼續錄音。

    選什麼才有聲音：
    • YouTube / 網頁影片 → 選「分頁（Tab）」+ 勾「共享分頁音訊」
    • Teams/Zoom 桌面版（Windows）→ 選「整個螢幕」+ 勾「共享系統音訊」
    • Teams/Zoom 桌面版（macOS）→ 改用瀏覽器版會議，再選分頁收音

注意事項

  • API Key 安全：Key 只存在瀏覽器記憶體，關閉頁面即消失，不會上傳或儲存
  • 音訊隱私：音訊由 Gemini（Google）處理，敏感內容請自行評估
  • 免費額度：每天約可轉錄 500 次，一般使用不會用完
  • 超過 18 MB 自動分段：長時間錄音（約 1.5 小時以上）會自動分段送出並繼續錄音
  • 遇到錯誤：系統會自動切換備用模型重試，通常不需要手動操作
  • 使用模型：主要使用 gemini-3.1-flash-lite，若遇到流量限制會自動切換至 gemini-3.5-flash-lite → gemini-2.5-flash-lite

常見問題

Q：按停止後要等多久？視錄音長度而定，1 小時的錄音大約等 30–60 秒。
Q：可以離線使用嗎？不行，需要連網才能呼叫 Gemini API。
Q：逐字稿儲存在哪裡？按「下載 Markdown」後儲存到你的電腦，網頁本身不保留任何資料。
