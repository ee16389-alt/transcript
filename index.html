模式 收音內容 適合場合

3. 「選什麼才有聲音」快速對照

  • YouTube / 線上影片：選擇「只收分頁」→ 彈窗中勾選「共享分頁音訊」。
  • Teams / Zoom 會議：選擇「麥克風＋分頁」→ 彈窗中選擇「整個螢幕」並勾選「共享系統音訊」。

4. 本機備份說明

  • 開始前選擇備份資料夾：每場錄音會建立獨立 .md 備份檔，錄音期間持續更新。
  • 錄音後才選擇：只會從目前已完成轉錄並顯示的內容開始備份；尚未轉錄完成的音訊不會另存。
  • 停止後仍有轉錄中的段落：完成後會繼續寫入同一場備份檔。
  • 未選擇資料夾：文字會暫存在瀏覽器，之後可存成備份或捨棄。
💻 Windows / macOS 系統選擇細節（點擊展開）
  • Windows 用戶：支援分享「整個螢幕」並同時擷取系統聲音，桌面版會議軟體（Teams/Zoom/Google Meet）皆可順暢收音。
  • macOS 用戶：因系統權限限制，建議將 Teams / Zoom 改用瀏覽器網頁版開啟，並選擇「分頁」收音才能成功抓取對方聲音。
❓ 常見問題 QA（點擊展開）
Q：沒有聲音時會產生文字嗎？ 系統會先偵測每段音訊是否有明確語音；若未偵測到聲音，會顯示「此段未偵測到明確語音」，並略過 API 轉錄。
Q：為什麼轉出的文字沒有聲音？ 請確認分享螢幕或分頁時，有勾選對話框左下角或下方的「共享音訊 / 分享系統聲音」核取方塊。
Q：錄音到一半會中斷嗎？ 當單段錄音達到你設定的「轉錄間隔」，或音訊接近 API 上限時，系統會自動在背景送出一段轉錄並繼續錄音，確保長會議也不中斷。
