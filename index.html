使用說明

事前準備

  • 需要一個 Gemini API Key（免費）
  • 取得方式：前往 aistudio.google.com → 登入 Google 帳號 → 點「Get API Key」→ 建立新 Key → 複製貼入上方欄位

使用步驟

  1. 將 API Key 貼入「Gemini API Key」欄位
  2. 選擇語言（預設繁體中文）
  3. 選擇是否需要即時翻譯
  4. 點「🎙 麥克風收音」或「🖥 分頁 / 視窗 / 螢幕收音」開始錄音
  5. 錄音完成後點「■ 停止收音」
  6. 等待幾秒，逐字稿自動出現
  7. 點「↓ 下載 Markdown」儲存到本機

兩種收音模式

  • 🎙 麥克風收音：收錄麥克風聲音，適合自己說話、會議發言
  • 🖥 分頁 / 視窗 / 螢幕收音：收錄瀏覽器分頁聲音，適合線上課程、YouTube、線上會議。點按鈕後選「分頁（Tab）」並勾選「共享分頁音訊」即可。電腦靜音也不影響轉錄。

注意事項

  • API Key 安全：Key 只存在瀏覽器記憶體，關閉頁面即消失，不會上傳或儲存
  • 音訊隱私：音訊由 Gemini（Google）處理，敏感內容請自行評估
  • 免費額度：每天約可轉錄 500 次，一般使用不會用完
  • 超過 18 MB 自動分段：長時間錄音（約 1.5 小時以上）會自動分段送出並繼續錄音
  • 遇到錯誤：系統會自動切換備用模型重試，通常不需要手動操作

常見問題

Q：按停止後要等多久？視錄音長度而定，1 小時的錄音大約等 30–60 秒。
Q：可以離線使用嗎？不行，需要連網才能呼叫 Gemini API。
Q：逐字稿儲存在哪裡？按「下載 Markdown」後儲存到你的電腦，網頁本身不保留任何資料。
